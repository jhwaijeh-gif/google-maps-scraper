Google Maps Scraper Kit

Ett gratis kit på GitHub som kör en riktig Google Maps-skrapa på din dator och låter Claude Code sköta den åt dig. Du skriver vad du letar efter och var. Tillbaka får du en CSV-fil, som du öppnar i Excel eller Google Kalkylark, med företagens namn, telefon, webbplats, adress och betyg.

Mejladresser letar kitet upp på företagens egna webbplatser, och Instagram, Facebook och LinkedIn också om du vill. Kitet är byggt för Claude Code, inte för ChatGPT. Det är gjort av Mahan, öppen källkod med MIT-licens och har över 1 300 stjärnor på GitHub.

Två program på datorn. Kitet fungerar på Windows, Mac och Linux.

Claude Code
claude.com

Styr skrapan åt dig, du skriver bara vad du letar efter. Ingår inte i gratisplanen. Den billigaste planen med Claude Code är Pro, 20 dollar i månaden eller 17 dollar i månaden vid årsbetalning, plus moms.

Vill du hålla allt gratis går kitets skript att köra direkt i terminalen, utan Claude. Då skriver du kommandona själv.

Kom igång

Har du Docker Desktop och Claude Code tar det runt fem minuter.
1

Ladda ner kitet

Öppna repot med knappen ovan. Tryck på den gröna knappen Code (1) och välj Download ZIP (2). Packa upp zip-filen, så har du en mapp med hela kitet.

2

Öppna mappen i Claude Code

Starta Docker Desktop först, det är där skrapan körs. Öppna sedan Claude-appen och tryck på fliken Code. Innan du skriver något väljer du Local och mappen du packade upp, den där filen SETUP.md ligger.

Kör du Claude Code i terminalen går du i stället till mappen och skriver claude.

Så installerar du Claude Code
3

Starta skrapan och be om listan

Skriv /scrape-setup och tryck Enter. Claude startar skrapan och kollar att den svarar. Första gången tar det runt fem minuter, mest för att Docker laddar ner motorn.

Sen skriver du bransch och stad med vanliga ord, som jag gjorde i videon: ”Hitta alla advokater som jobbar i Stockholm”. Claude frågar om du vill ha Instagram, Facebook och LinkedIn också och sparar listan som en CSV-fil. Räkna med några dussin till några hundra företag per sökning, inte varenda en.

Kör en sökning i taget. Att skrapa Google Maps går emot Googles villkor, och för många sökningar på en gång kan ge en tillfällig spärr.

Använd listan schyst. Namn, direktnummer och mejl som förnamn.efternamn@företag.se är personuppgifter enligt GDPR, även när de ligger öppet på nätet. Berätta vid första kontakten var du hittade uppgifterna, sluta om någon säger nej och radera det du inte behöver. Reklam via mejl och sms till privatpersoner kräver samtycke i förväg.
